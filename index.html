    Otomatik kapaklar

    Dizi kapakları anahtarsız gelir (TVmaze). Film kapakları ve Türkçe adlar için ücretsiz bir TMDB anahtarı gerekir.

    TMDB anahtarını nasıl alırım? (5 dakika)
    1. themoviedb.org/signup sayfasında ücretsiz hesap aç.
    2. E-postana gelen doğrulama bağlantısına tıkla, sonra giriş yap.
    3. Ayarlar → API sayfasını aç ve Create / click here bağlantısına bas.
    4. Tür olarak Developer'ı seç, kullanım şartlarını oku ve kabul et.
    5. Formu doldur: Type of Use: Personal · Application Name: Seyirlik · Application URL: http://localhost:8769 · Application Summary: Kişisel film ve dizi izleme listem; kapak ve bilgi göstermek için. Ad, adres ve telefon alanlarına kendi bilgilerini yaz.
    6. Submit'e bas. Açılan sayfadaki API Key değerini (32 karakterlik harf-rakam) kopyala. Uzun API Read Access Token da çalışır.
    7. Aşağıdaki kutuya yapıştır ve Kaydet'e bas. “Anahtar çalışıyor ✓” yazısını görünce film kapakları gelmeye başlar.

    Yedek

    Listen bu tarayıcıda saklanıyor. Başka bilgisayara taşımak ya da güvende tutmak için yedek dosyası indir.
